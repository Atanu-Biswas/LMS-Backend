# Library Management System

## 📘 Project Overview
[cite_start]This project revolutionizes traditional library management by embracing modern technology to streamline library operations[cite: 15]. [cite_start]Designed with a focus on user-friendly solutions, the system manages everything from user registration to book issuances and returns[cite: 16]. [cite_start]The primary goal is to enhance librarian efficiency and provide users with a seamless borrowing experience, ultimately fostering a culture of learning and knowledge dissemination[cite: 17, 18].

## 🛠 Tech Stack
[cite_start]The project utilizes a comprehensive modern technology stack[cite: 133]:
* **Backend:** Java, Spring Boot
* **Frontend:** Angular, TypeScript, Bootstrap
* **Database:** Oracle Database
* **Design & Version Control:** Figma, Git

## ✨ Key Features

### Core Functionality
* [cite_start]**Real-Time Availability:** Efficient monitoring of book availability in real-time[cite: 30].
* [cite_start]**Security:** Enhanced security using JWT authentication and encrypted password protection[cite: 50].
* **Notifications:**
    * [cite_start]**Email Alerts:** Automated emails for user registration, book issuance, and returns[cite: 39].
    * [cite_start]**New Arrivals:** Dashboard updates for new book additions, keeping users informed for two weeks after a book is added[cite: 28, 29].

### 👤 User Module
[cite_start]Designed for a seamless user experience with a centralized dashboard[cite: 96].
* [cite_start]**Search & Explore:** Easy book search functionality with filters to discover new titles and authors[cite: 25, 104].
* [cite_start]**Borrowing Management:** Quick issuance requests and tracking of borrowed books to ensure timely returns[cite: 26, 105].
* [cite_start]**Fine Tracking:** Monitor fines for overdue books directly on the user dashboard[cite: 37].
* [cite_start]**Profile Management:** Seamlessly update user profiles to keep information current[cite: 56].

### 🛡️ Admin Module
Empowers administrators to oversee the library's inventory and users.
* [cite_start]**Book Management:** Simplified addition of new books and control over book availability and details[cite: 21, 115].
* [cite_start]**Request Handling:** Review and approve or reject borrowing requests[cite: 117].
* [cite_start]**User Oversight:** Visibility into user accounts, including their fines and currently borrowed books[cite: 117].
* [cite_start]**Dashboard:** A central hub to monitor key metrics, track user interactions, and access reports[cite: 116].
